# Little Foundry

A small, animated factory-management browser game prototype.

## Prototype
- Watch the isometric workshop run: smelter, press, assembly line, moving crates, workers, steam and sparks.
- Resources accumulate automatically while the factory is running.
- Spend credits, iron and gears on upgrades.
- Fill delivery orders to earn rewards and progress through shifts.
- Pause the factory or make a little shower of sparks.
- Progress is saved locally in the browser.

## Run locally
Open `index.html` in a modern browser. The game is a static HTML/CSS/JavaScript page with a canvas-rendered scene; no build step is required.

## Hosting
