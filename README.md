# IRONBOUND

A self-contained, single-player idle/clicker strategy game about building a kingdom's war economy and driving the orcs from the realm.

## Play

Once the GitHub Pages workflow has completed, play at:

**https://jonatannorrby.github.io/ironbound/**

## Gameplay

- Gather timber, stone, iron, provisions and coin.
- Build and upgrade production buildings.
- Recruit militia, archers, knights and siege engines.
- Research improved tools, military drills, supply trains, siegecraft and stewardship.
- Launch campaigns across six regions. Campaigns consume supplies, and an underpowered army can be repelled.
- Secure territory for production bonuses and resource spoils.
- Progress is saved in your browser, with up to eight hours of offline production applied when you return.

## Development

The game is plain HTML, CSS and JavaScript in index.html; it has no build step or external dependencies.

Pushing to main triggers .github/workflows/pages.yml, which deploys the repository to GitHub Pages.
